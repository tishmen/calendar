=====================
Web Resource Booking
=====================

Public portal entry to create resource bookings and redirect visitors to the
existing scheduler. Provides a one-page form to select a booking type, pick a
staff user, and enter name/email. Creates a booking and opens the schedule page.

Usage
-----

- Navigate to `/rbooking`
- Select a booking type and staff member
- Enter your name and email, then continue to schedule
