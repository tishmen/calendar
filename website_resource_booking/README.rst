Website Resource Booking
========================

Website snippet to surface a public booking entry point for resource bookings.

Features
--------
- Adds a snippet group and a simple card linking to the public booking page.
- Provides preview data for the website editor.

Usage
-----
Install the module, open the website editor, and drag the "Resource Booking"
snippet into a page. Configure the link to point to your public booking route.
